## 1.1.0

- Colour rules in the right order: specific blocks (redstone, end stone, glowstone …) before the broad families – "stone" no longer catches "redstone_block"; whole-word matching; the colours are documented (average vanilla texture colour) and tested. / Farbregeln in richtiger Reihenfolge, begründet und getestet.
- Vanilla structure files (.nbt from structure blocks and data packs) are recognised – in the list, the file preview and the 3D view. / Vanilla-.nbt wird erkannt.
- Layer slider: look at a build layer by layer from the bottom. / Ebenen-Schieber.
- Material list: every block type with count and stacks of 64 (hidden blocks included), copy as text. / Materialliste.
- Tab "Builds" in Hostwerk's Minecraft area with a choice of server. / Reiter im Minecraft-Bereich.
- Save the current view as a PNG picture. / Als Bild exportieren.
- Error states with "Try again", numbers in Hostwerk's language, sizes from the design scale, place in the sidebar right after Minecraft, other extensions may add tabs. / Fehlerzustände, Design-Skala, Seitenleiste.

## 1.0.0

- First release as its own extension (before: built into Hostwerk). Data stays where it was. / Erste Fassung als eigene Erweiterung (vorher fest in Hostwerk). Daten bleiben, wo sie waren.
