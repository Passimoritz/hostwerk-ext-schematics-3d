## 1.3.0

- Material list with German block names in the German interface and a search (name or block ID); search and server choice stay on top while scrolling the file list. / Materialliste mit deutschen Blocknamen in der deutschen Oberfläche und einer Suche (Name oder Block-ID); Suche und Server-Auswahl bleiben beim Scrollen der Dateiliste oben.
- Much faster and safe with damaged or oversized files (seconds and up to 1 GB before → milliseconds), clear error messages instead of technical ones, builds in world/generated/ are found. / Viel schneller und sicher bei kaputten oder übergroßen Dateien (vorher Sekunden und bis zu 1 GB → Millisekunden), verständliche statt technischer Fehlermeldungen, Bauwerke in world/generated/ werden gefunden.
- Fixes: empty builds show a hint instead of empty tools, “1 block” instead of “1 blocks”, CSV with decimal comma in German, comparison is reset when switching files. Needs Hostwerk 3.2 (file browser slots). / Korrekturen: leere Bauwerke zeigen einen Hinweis statt leerer Werkzeuge, „1 Block“ statt „1 Blöcke“, CSV mit Dezimalkomma auf Deutsch, Vergleich wird beim Dateiwechsel verworfen. Braucht Hostwerk 3.2 (Datei-Browser-Anschlüsse).

## 1.2.2

- New animated icon and banner in the common Hostwerk style (isometric block). / Neues animiertes Symbol und Banner im gemeinsamen Hostwerk-Stil (isometrischer Block).

## 1.2.1

- Lives where it belongs: Files (right-click “View in 3D” and the preview) – no own sidebar entry any more (Hostwerk 3.0+); the full page stays under Extensions → Open and can be pinned in the sidebar settings. / Steckt jetzt dort, wo sie hingehört: Dateien (Rechtsklick „In 3D ansehen“ und Vorschau) – kein eigener Seitenleisten-Eintrag mehr (Hostwerk 3.0+); die ganze Seite bleibt unter Erweiterungen → Öffnen und lässt sich in den Seitenleisten-Einstellungen anheften.

## 1.2.0

- Lives in the file browser now: the 3D view is the preview of build files, and the right-click menu offers “View in 3D” (Hostwerk with SDK 3.2). The tab in the Minecraft area is gone; the own page stays optional (sidebar under Files). / Zuhause im Datei-Browser: Vorschau in 3D und Rechtsklick „In 3D ansehen“; der Reiter im Minecraft-Bereich entfällt, die eigene Seite bleibt optional (Seitenleiste unter Dateien).
- Layer slice “Only this layer”, material list as CSV, comparison with another build in the same folder (which blocks changed). / Ebenen-Schnitt, Materialliste als CSV, Vergleich mit einem anderen Bauwerk im selben Ordner.
- Keyboard: arrows rotate, + / − zoom, Page up/down change the layer, 0 resets the view. / Tastatur: Pfeile drehen, + / − zoomt, Bild auf/ab wechselt die Ebene, 0 setzt zurück.

## 1.1.0

- Colour rules in the right order: specific blocks (redstone, end stone, glowstone …) before the broad families – "stone" no longer catches "redstone_block"; whole-word matching; the colours are documented (average vanilla texture colour) and tested. / Farbregeln in richtiger Reihenfolge, begründet und getestet.
- Vanilla structure files (.nbt from structure blocks and data packs) are recognised – in the list, the file preview and the 3D view. / Vanilla-.nbt wird erkannt.
- Layer slider: look at a build layer by layer from the bottom. / Ebenen-Schieber.
- Material list: every block type with count and stacks of 64 (hidden blocks included), copy as text. / Materialliste.
- Tab "Builds" in Hostwerk's Minecraft area with a choice of server. / Reiter im Minecraft-Bereich.
- Save the current view as a PNG picture. / Als Bild exportieren.
- Error states with "Try again", numbers in Hostwerk's language, sizes from the design scale, place in the sidebar right after Minecraft, other extensions may add tabs. / Fehlerzustände, Design-Skala, Seitenleiste.

## 1.0.0

- First release as its own extension (before: built into Hostwerk). Data stays where it was. / Erste Fassung als eigene Erweiterung (vorher fest in Hostwerk). Daten bleiben, wo sie waren.
